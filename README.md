# Quidditch

Download-Seite für das Quidditch-Spiel — ein Besenflug-Spiel, gebaut mit Unreal Engine 5.8.

Die Seite liegt in `index.html` und wird über GitHub Pages ausgeliefert.
Die Spieldateien selbst hängen unter **Releases**.

## Neue Version eintragen

In `index.html` ganz unten im `<script>`-Teil steht die Liste `VERSIONEN`.
Einen neuen Block oben anfügen, `url` auf die Adresse der Release-Datei zeigen lassen.
